# EcoRuta - Sistema de colores y reglas visuales

## 1. Objetivo visual
La identidad de EcoRuta debe transmitir:
- calidez humana,
- confianza y seguridad,
- formalidad institucional,
- claridad operativa,
- cercanía con la comunidad.

La combinación debe sentirse profesional y confiable, como una solución enfocada a gobierno y servicio público, pero sin perder empatía hacia la ciudadanía.

---

## 2. Paleta principal

### 2.1 Colores base
- Verde institucional: #2E7D32
  - Uso principal para identidad, navegación principal, estados positivos y acciones de confianza.
- Verde profundo / bosque: #1F4D3A
  - Uso para títulos, encabezados, menús principales y elementos de autoridad institucional.
- Azul confianza: #1F5F8C
  - Uso para información, enlaces secundarios, botones de acción institucional y detalles de mapa.
- Crema cálida: #F7F3E8
  - Fondo general para generar sensación de calidez y una estética más amable.
- Blanco limpio: #FFFFFF
  - Fondos de tarjetas, formularios y pantallas de contenido.
- Gris grafito: #263238
  - Para textos principales, títulos y elementos de alta legibilidad.
- Gris suave: #6B7280
  - Para textos secundarios, placeholders y metadatos.

### 2.2 Colores de acento
- Ámbar cálido: #F4B942
  - Uso para avisos, secciones de alerta moderada, notificaciones de proximidad y estados “en proceso”.
- Rojo alerta: #D64545
  - Uso para fallas, cancelaciones, alertas graves y prioridad máxima.
- Verde éxito: #4CAF50
  - Uso para confirmar operaciones exitosas, rutas completadas y estados en buen funcionamiento.
- Naranja de servicio: #E67E22
  - Uso para advertencias operativas y retrasos leves.
- Azul claro de información: #EAF3FF
  - Uso para fondos auxiliares y estados informativos.

---

## 3. Regla general de aplicación

### 3.1 Titulos y encabezados
- Títulos principales: verde profundo #1F4D3A o gris grafito #263238.
- Subtítulos: gris grafito #263238.
- Títulos de tarjetas o secciones: verde institucional #2E7D32.

Regla:
- Los títulos deben verse firmes y formales.
- Evitar usar demasiados colores distintos en un mismo bloque.

### 3.2 Botones

#### Botón principal
- Fondo: verde institucional #2E7D32
- Texto: blanco #FFFFFF
- Hover: verde más oscuro #225E2A
- Corner radius: redondeado moderado, 10-12px

Uso:
- Inicio de sesión
- Guardar
- Enviar reporte
- Confirmar acción importante

#### Botón secundario
- Fondo: blanco #FFFFFF
- Bordes: verde institucional #2E7D32
- Texto: verde institucional #2E7D32

Uso:
- Cancelar
- Volver
- Ver detalle
- Acción complementaria

#### Botón de advertencia
- Fondo: ámbar cálido #F4B942
- Texto: gris grafito #263238

Uso:
- Notificaciones de cercanía
- Avisos moderados
- Reprogramación o retraso leve

#### Botón de peligro / alerta
- Fondo: rojo alerta #D64545
- Texto: blanco #FFFFFF

Uso:
- Cancelar ruta
- Reporte crítico
- Alerta de paro o falla del camión

### 3.3 Fondos y superficies
- Fondo general de app/web: crema cálida #F7F3E8
- Tarjetas: blanco #FFFFFF
- Panel administrativo: blanco o crema muy claro
- Menú lateral principal: verde profundo #1F4D3A
- Menú lateral texto: blanco #FFFFFF

Regla:
- Mantener el fondo cálido para no sentirse frío o demasiado técnico.
- Las tarjetas deben verse limpias y formales, no sobrecargadas.

### 3.4 Inputs y formularios
- Fondo: blanco #FFFFFF
- Borde: gris suave #CBD5E1 o #DADDE3
- Focus: azul confianza #1F5F8C
- Placeholder: gris suave #6B7280

Uso:
- Login, formularios de rutas, reportes, configuración.

### 3.5 Estado de rutas y alertas
- En ruta normal: verde éxito #4CAF50
- Retraso: ámbar cálido #F4B942
- Desviación: naranja de servicio #E67E22
- Falla / paro crítico: rojo alerta #D64545
- Cancelado: gris oscuro #52606D

Regla:
- Los colores de estado deben ser consistentes en mapa, tickets, alertas y panel administrativo.

---

## 4. Reglas de diseño visual por módulo

### 4.1 Web administrativa
- Fondo principal: crema cálida #F7F3E8
- Encabezados: verde profundo #1F4D3A
- KPIs y paneles: blanco con bordes suaves y acento verde
- Mapa de rutas: base neutrales con marcadores verdes/ámbar/rojo según estado
- Acciones críticas: rojo o ámbar según intensidad

Objetivo:
- Dar una sensación de control, confianza y seriedad operativa.

### 4.2 App Ciudadano
- Fondo principal: blanco y crema suave
- Acciones principales: verde institucional para ver ubicación y reportar
- Notificaciones: ámbar para avisos y rojo para fallas
- Mapas: azul para rutas y verde para camiones activos

Objetivo:
- Que la app se sienta útil, amigable y confiable para la comunidad.

### 4.3 App Operador
- Fondo de trabajo: blanco con acentos verdes y azules
- Botones clave: verde institucional
- Alertas críticas: rojo
- Indicadores de estado: verde, ámbar, naranja, rojo

Objetivo:
- Mantener velocidad operativa y control sin perder formalidad.

---

## 5. Tipografía recomendada
Aunque este documento se centra en color, la tipografía debe complementar la identidad:
- Títulos: Poppins, Montserrat o Sora
- Texto general: Inter, Open Sans o Roboto
- Estilo: limpio, moderno, serio y legible

Regla:
- No mezclar demasiadas tipografías. Usar 1 para títulos y 1 para texto general.

---

## 6. Contraste y accesibilidad
Se recomienda mantener:
- textos principales en gris grafito #263238 o negro #111827,
- fondo claro para lecturas cómodas,
- botones con alto contraste para facilitar uso en exteriores y pantallas móviles,
- no usar verde claro sobre blanco para texto importante, porque puede perder legibilidad.

Regla mínima:
- Todo texto importante debe tener contraste suficiente para ser leído sin esfuerzo.

## 8. Regla final de marca
EcoRuta debe verse como una solución:
- humana y cercana,
- institucional y confiable,
- moderna y funcional,
- diseñada para servir a la comunidad con responsabilidad.

La combinación de verde + crema + azul profundo genera la sensación correcta: servicio público con calidez, pero con autoridad y orden.

---

## 9. Recomendación práctica para implementación
- Usar verde institucional como color dominante del sistema.
- Usar crema como fondo base para suavizar la sensación formal.
- Usar azul para elementos de información y mapa.
- Usar ámbar y rojo solo para alertas y estados críticos.
- Mantener un máximo de 3 colores primarios y 2 colores de acento en la interfaz principal.

Esto evitará que la app se vea caótica o demasiado “de gobierno frío”, y la hará más agradable para la comunidad.
